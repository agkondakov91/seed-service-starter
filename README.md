# seed-service

Сквозной учебный сервис на FastAPI — база для курса «Обеспечение качества функционирования компьютерных систем». Это состояние на конец курса «Дорога в прод»: сервис воспроизводим, контейнеризирован, настроен и снабжён пайплайном.

## Что умеет

- `GET /` — приветствие из настроек
- `GET /health` — проверка живости
- `GET /db-check` — проверка связи с базой

## Что нужно поставить

- [uv](https://docs.astral.sh/uv/), Docker, git.

## Как запустить

Весь стек (приложение + PostgreSQL) одной командой:

```bash
docker compose up --build
```

Проверка: <http://localhost:8000/> и <http://localhost:8000/db-check>.

Локально без Docker (нужен запущенный PostgreSQL по адресу из `.env`):

```bash
uv sync
uv run uvicorn main:app --reload
```

## Настройки

Все настройки — в `.env` (в репозиторий не коммитится, шаблон — `.env.example`):

- `GREETING` — текст приветствия
- `DATABASE_URL` — строка подключения к базе
- `POSTGRES_PASSWORD` — пароль базы (используется Compose)

## Проверки и релизы

- CI (линт + тесты) — на каждый push и pull request
- публикация образа в ghcr.io — из `main` (тег `latest`) и по git-тегу `vX.Y.Z` (версия)
