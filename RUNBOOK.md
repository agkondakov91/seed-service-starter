# Runbook: seed-service

Короткие инструкции для дежурного. Каждый шаг — команда. Секреты здесь не храним.

## Сервис не отвечает

Симптом: / или /health не отвечают, пользователи видят ошибки.

1. Жив ли сервис:          curl -s http://ПРОД/health
2. Запущены ли контейнеры: docker compose ps
   (app не running → docker compose up -d)
3. Что в логах:            docker compose logs --tail=50 app
4. Доступна ли база:       curl -s http://ПРОД/db-check
5. Был недавно релиз? → откат: сменить тег образа на предыдущий
   (например :v1.0.0) и docker compose up -d
6. Не помогло за 15 минут → эскалация: позвать владельца сервиса
